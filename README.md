# Fancy Words

Strona ze słówkami na writing z angielskiego: im bardziej wypasione słówko, tym więcej punktów.

- **Ranking:** wszystkie słówka posortowane po punktach (1–5), wyszukiwarka, filtry, licznik użyć.
- **🔥 Daily:** codziennie 5 zdań z lukami (open cloze), ten sam zestaw dla całej klasy, punkty, podpowiedzi za ½ pkt, seria dni i wynik do skopiowania.
- **Policz writing:** wklejasz tekst, strona podświetla słówka z listy i liczy punkty.

## Jak edytować słówka
Słówka są w `words.js`, zdania do Daily w `sentences.js`. Wszystko w `words.js`: `en`, `pl`, `pts` (1–5), `cat`, opcjonalnie `alt` (inne formy).

## Uruchomienie
Czysty HTML/JS, bez builda. Otwórz `index.html` albo włącz GitHub Pages (Settings → Pages → branch `main`, folder `/`).
